# Project working instructions

- Work in small milestones. After completing a milestone, explain what changed and what we learned, then stop for discussion before starting the next milestone.
- Document each completed step or substantive topic in `docs/` using a descriptive Markdown filename. Update `docs/README.md` when adding a document.
- Record the purpose, commands or files involved, observed results, decisions, limitations, and next step. Distinguish completed work from proposals. Use the user's Europe/Budapest date for new entries.
- Update documentation in the same change as the work it describes. Keep experiment results in the relevant topic document; preserve machine-readable results separately when available.
- Do not describe printed model commands as executed or functionally validated. Keep raw output, first-line extraction, syntax checks, and functional evaluation distinct.
